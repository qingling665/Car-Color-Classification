# Car-Color-Classification: 深度學習汽車顏色辨識

## 專案簡介
這是一個電腦視覺的實作專案，主要任務是透過影像分類技術來辨識汽車的顏色。專案的重點不在於無腦套用最深的神經網路，而是實際搭建不同的 CNN 與 Transformer 架構，並探討在相同的資料集下，不同模型的「準確率」與「訓練時間」的 CP 值。

## 資料集 (Dataset)
*   **來源**：採用 Roboflow 上的 Car Colors 資料集。
*   **資料規模**：總計 2004 張真實車輛圖片，切分為訓練集 (1396張)、測試集 (395張) 與驗證集 (213張)。
*   **分類類別**：共 9 類（黑、藍、綠、灰、橘、紅、銀、白、黃）。
*   **前處理**：有特別針對訓練集確認過各顏色的資料筆數（皆落在 134~171 張之間），確保模型不會因為資料不平衡 (Imbalanced Data) 而產生預測偏誤。

## 實作與模型比較
專案中實作並比較了四種不同的模型架構：YOLOv8-Classification、Vision Transformer (ViT)、ResNet-32 以及 VGG-19。我們也親自用 Keras 刻了 VGG-19 的底層結構（包含 Conv2D, MaxPooling, Dropout 等層）來加深對 CNN 特徵萃取的理解。

### 實驗結果
在優化超參數（Epochs=50, Batch_size=16）後，各模型的測試結果如下：
1.  **YOLOv8 (Nano)**：表現最佳，準確率達到 88.4%，訓練時間約 11.3 分鐘。
2.  **ResNet-32**：準確率達到 81.58%，且受惠於殘差網路架構，訓練時間僅需 7.1 分鐘，是整體訓練效率最高的模型。
3.  **Vision Transformer**：準確率約 72.4%，但訓練時間長達 50.57 分鐘，在小資料集上反而顯得過於笨重。
4.  **VGG-19**：準確率約 71.36%，訓練時間約 24.76 分鐘。

## 結論與學習
透過這次實作，我深刻體會到模型並非「越深越好」或「越新越好」。在資料量約兩千張的任務中，輕量化的 YOLOv8-cls 與 ResNet-32 能夠在訓練時間與準確率上取得最好的平衡。
